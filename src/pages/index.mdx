#### Something to Geek Out On

<aside class="bg-surface-container-lowest p-6 rounded-lg border border-white/[0.02] font-mono text-sm leading-relaxed mb-10">

* My resume is structured using the [JSON Resume standard](https://jsonresume.org/) (see [resume.clintp.json](https://raw.githubusercontent.com/yuhonas/clintp.xyz/main/resume/resume.clintp.json)).
* Explore the raw resume data using [jsoncrack.com](https://jsoncrack.com/editor?json=https://raw.githubusercontent.com/yuhonas/clintp.xyz/main/resume/resume.clintp.json) or query it via [lite.datasette.io](https://lite.datasette.io/?json=https://raw.githubusercontent.com/yuhonas/clintp.xyz/main/resume/resume.clintp.json#/data/resume?_sort=rowid&_facet=name&_facet=location).
* There is a [data transformation pipeline](https://github.com/yuhonas/clintp.xyz/blob/main/resume/resume-transform.py) written in [Spotify's Luigi](https://github.com/spotify/luigi) that produces a number of [artifacts](https://github.com/yuhonas/clintp.xyz/tree/main/resume/build) from my resume data, like a [Career Timeline](https://cdn.knightlab.com/libs/timeline3/latest/embed/index.html?source=https://raw.githubusercontent.com/yuhonas/clintp.xyz/main/resume/build/timeline.json&font=Default&lang=en&hash_bookmark=true&initial_zoom=2&height=650#event-co-owner) and a contact [QR Code](https://github.com/yuhonas/clintp.xyz/blob/main/resume/build/clintp-qrcode.gif).
* The [CI workflow](https://github.com/yuhonas/clintp.xyz/blob/main/.github/workflows/ci.yml) updates a gist to automatically publish the resume on [registry.jsonresume.com](https://registry.jsonresume.org/yuhonas) (e.g., using [Stack Overflow](https://registry.jsonresume.org/yuhonas?theme=stackoverflow) or [Lucide](https://registry.jsonresume.org/yuhonas?theme=lucide) themes).
* [E2E tests](https://github.com/yuhonas/clintp.xyz/blob/main/cypress/e2e/site.cy.js) run on every commit to ensure the good stuff happens and the bad stuff doesn't.
* Structured SEO data ([JSON-LD](https://json-ld.org) / [Schema.org](https://schema.org)) is generated via [SchemaMarkup.astro](https://github.com/yuhonas/clintp.xyz/blob/main/src/components/SchemaMarkup.astro) to support [rich results](https://developers.google.com/search/docs/appearance/structured-data/search-gallery?sjid=5186190557907869630-NC) and can be viewed at [schema.org](https://validator.schema.org/#url=https%3A%2F%2Fclintp.xyz%2F).
* AI assists with ideation/production and design implementation (see [AGENTS.md](https://github.com/yuhonas/clintp.xyz/blob/main/AGENTS.md) and [design-system.md](https://github.com/yuhonas/clintp.xyz/blob/main/.ai/design-system.md)).

</aside>
